# charts/

Componentes de gráficos:

- `CandleChart`: TradingView Lightweight Charts. Velas, EMAs, VWAP, S/R,
  plan (entrada, stop, TPs, liquidación, zonas sombreadas), fondo por régimen
  y paneles sincronizados de volumen, RSI y MACD (Hito 7).
- `ScoreGauge`, `Sparkline`, barras divergentes, donuts, heatmap de
  transiciones, Monte Carlo: Recharts (Hitos 7 y 9).
